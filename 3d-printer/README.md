# 3D Printer Projects

This folder stores durable state and reference material for printer builds, firmware, tuning, parts, and maintenance.

## Active project
- [`mercury-one-1/`](./mercury-one-1/) — Ender 5 Pro → ZeroG Mercury One.1 CoreXY conversion.

## Conventions
- `OWNED` = physically on hand and verified.
- `ORDERED` = purchased but not yet verified in hand.
- `PENDING` = intended purchase / decision not completed.
- `TBD` = not yet determined.
- `LOCKED` = user explicitly selected this configuration unless later changed.
